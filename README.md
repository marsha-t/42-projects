# 42 Projects

A curated overview of the projects I completed during the 42 Abu Dhabi curriculum.

This repository acts as an index to the individual project repositories, with short descriptions highlighting the key concepts explored in each project.

42 Abu Dhabi is a project-based software engineering school with a peer-learning model, emphasizing systems programming, problem solving, and collaboration.

## Featured Projects

Selected projects that best represent my experience in systems programming, networking, and full-stack development:

**[ft_transcendence](https://github.com/marsha-t/ft_transcendence)**  
Real-time Pong platform built as a full-stack team project using a microservices architecture.  
_TypeScript, Fastify, Docker, Nginx_

**[webserv](https://github.com/marsha-t/webserv)**  
HTTP/1.1 server in C++98 using non-blocking sockets and an event-driven architecture.  
_Sockets, HTTP protocol, request parsing, concurrency_

**[Leaffliction](https://github.com/marsha-t/leaffliction)**  
Computer vision project building an end-to-end image classification pipeline for plant disease recognition.
_Python, PyTorch, CNNs, image processing_

## From Common Core to Mastery

The Common Core built my foundations in low-level programming, algorithms, systems, networking, and software engineering. Through the Mastery curriculum, I'm extending those foundations into Python, mathematics, machine learning, and computer vision.

The projects above trace that progression from implementing fundamental abstractions in C and building network servers from scratch to implementing ML algorithms and training image classifiers with PyTorch.
